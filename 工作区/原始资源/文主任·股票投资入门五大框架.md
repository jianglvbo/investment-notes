# 一、思维思想篇：理念与心态修炼

首先，刚入门股票市场的朋友我认为最应该认识到的一件事情就是，投资赚钱非常难。很多人在网上看一些蛊惑人心的引流视频，可能会觉得炒股很简单，看看线，听听内幕消息，并且过度相信股票市场的造富神话。

我们应该清醒的认知到，投资赚钱是非常难的事情。钱难赚屎难吃，这个世界上没有容易的赚钱方法，金融市场也一样。如果自己没有花费过大量精力去仔细研究经济、市场、公司、价格运行，是不可能在金融市场长久持续的赚钱的。

不知道大家是否记得徐翔这个人，曾经他的下属写过一篇描述他的文章，"他每天研究股市超过12小时，几乎没有娱乐和其他爱好，据我所知，这种习惯已经持续了20多年。毫无疑问，徐翔是我见过的最为勤奋和专注的投资人，没有之一。"

当然第二个要认知到的，就是投资又没有那么难，甚至有时候很简单。很多东西我们都可以靠常识去判断。金融市场火热的时候，人们总是对标的赋予了太多的"想象"。

我个人在市场上总是非常纠结的，我投资交易的信条就是"怀疑"二字。怀疑自己，怀疑市场。在24年我取得了惊人的40+%收益结果后，我对自己加深了怀疑。同时基于一点技术面的判断，25年年初大幅度减仓。本意是在24年的大胜后让自己冷静一段时间，但也因此躲过了4月的恐慌行情。投资切忌"确定性"，这三个字本身就是巨大的不确定性（风险）。

又比如，哪怕谷歌的投资给我带来了巨大的收益，我也在不断怀疑他的业绩发展，AI是否真的如同搜索一般有很强的用户粘性？目前没有，在没有用户粘性的情况下，能否转化成谷歌持续的经营利润？不知道。如果美国经济下行，谷歌的广告业务是否具备足够的防御力？怀疑自己，怀疑市场，这是让我们在市场中获得更久的哲学。

胡猛说过，投资回报只取决于：1. 风险控制，2. 勤奋，3. 耐心。美股有很多好公司，A股也有很多好公司，港股也有很多好公司。好的东西遍地都是，但是并不是每一家好公司，都是合适的价格。绝大多数的时候，我认为投资者应该是在勤奋的研究，而非频繁的买卖（期权衍生品除外）。在没有好价格的时候，多研究，多读多看多想，跟踪市场，等风来。只要你耐心足够，风会将好资产吹到你的脚边，你要做的，就是低头弯腰，轻轻捡起。

还有，很多散户在投资交易中总是关注收益，但其实我觉得更应该关注风险。回撤管理才是首要目标。散户最喜欢做的事情就是什么都不做，涨着，躺着，等着，套着。在每一笔交易我去进行之前，都会有个大致的心理预期判断。当市场行情超出我心理预期时，我会选择减仓或者进行盈利的保护。

例如阿里。在今年市场一致看好恒科看好阿里时，通过财报的阅读（云业务表现亮眼，但其他方面拉垮，现金流甚至有倒退），我们可以明显看出那时的阿里更多是靠想象空间支撑，更像一笔"风险投资"。（当然，目前我仍认为阿里是一笔值得的风险投资。）在阿里冲上190，市场集体高潮的时候，我默默的做了一笔几乎0成本的Collar策略。

情绪高时要减仓，情绪低时要加仓，是短周期管理的关键。这句话说起来容易，做起来艰难无比，太反人性了。比起抄底，我更喜欢逃顶。因为如果我不抄底，顶多不赚，至少不会亏。但如果我不逃顶，是会带来实打实的财富缩水的。权重管理更重要的是让我们在颠簸的市场中保持好心态。专业投资者与业余投资者的区别就是在熊市能否赚到钱。业余投资者在牛市可能表现更好，因为他们更无畏。而熊市需要考验投资者的组合构造、权重管理、做空能力。

总而言之，投资交易是一件很有意思的事情，通过投资交易赚钱不是一日可成的事情，研究商业模式，享受市场的波动，磨练自己的心性，日积月累，相信你也能形成自己的框架，在市场中获得属于你的一桶金。

# 二、技术分析篇：工具与交易纪律

傅海棠说："重仓猛干，浮盈加仓，频繁交易，技术分析。"不少朋友听完这四句话就去实践了，殊不知后面还有一句"基本没好。"这四句话也被誉为炒股的四大忌讳。

段永平也说，看线炒股的都是韭菜。我们是否因此就完全否定技术分析呢？我认为完全不是。

像钓鱼，钓无定法。不必拘泥于操作的形式、流派，不管黑猫白猫，只要能抓到老鼠，都是好猫。

当然，纯技术分析我是十分不认可的，绝大部分散户朋友认为依赖技术分析可以精准择时，甚至迷恋各种图形、指标，这是不可能长久赚钱的。各种技术图形，是市场走出来的，而不是画出来的，我们运用技术分析并不是为了预测未来，而是更清楚的了解当下市场的价格运行到了什么情况。如果有自己用的顺手的技术指标，叠加基本面的分析和宏观事件的分析，整体投资的胜率将大大提升。

我最常用的技术指标是BOLL布林线、RSI相对强弱指标、偏离度（乖离率）、200日均线、850日均线、60日均线、20日均线、BBI。

在技术分析篇章，仅以我最常用的布林线战法为例，讲解技术面在买卖点上的判断辅助作用。如果大家对RSI、偏离度等感兴趣，后续我可以继续出文章进行详细讲解。但授人予鱼不如授人予渔，各位对于自己感兴趣的技术指标，一般在各大证券软件内，都有相对应的指标介绍会进行简单的讲解。

## 2.1 核心工具：布林线（BOLL）用法解析

技术分析部分，就以BOLL布林线给大家讲解。布林线由约翰·布林（John Bollinger）发明，是技术分析中最实用、流传最广的指标之一。它利用统计学中的标准差原理，构建了一个价格波动的"范围"。当我们点开BOLL，股票界面会出现三条线，分别称为上轨道、中轨道和下轨道。

布林线背后的逻辑是基于正态分布原理，以均线为中轴，利用2倍标准差构建区间；统计学上，约95%的价格波动会落在此区间内。简单来说，就是布林上下轨道之间，是大概率事件，而上下轨道之外，是小概率事件。

我个人认为布林线的用法有三种：做震荡，做趋势，做反转。

### 2.1.1 用法一：震荡行情操作

如果我们看到布林通道整体呈现走平的趋势，或者你认为接下来市场没有什么催化剂，大概率会走平，那就可以以布林上下轨为界限。因为股价有95%的情况会在上下轨波动，因此触达下轨则做多，触达上轨做空。在震荡中获取收益。

当然我们也需要知道什么情况下震荡趋势会结束，在市场从震荡市转为向上或向下的行情时，如果你不果断结束，可能会遭受不小的损失。

布林线的宽窄变化可以作为一个参考。如果我们在一段震荡中来回做了几个波段，突然发现布林的上下轨宽度变宽，说明市场可能要转变了，这时候应该果断退出（止损）震荡市的做法，转为做趋势。

### 2.1.2 用法二：趋势行情操作

一段趋势的走出可以是向上，或者向下的。如果体现在布林线中，就是沿着布林线上轨道单边上涨，或者沿着布林下轨道单边下跌。

如果观测到布林刚刚结束一段平行震荡走势，并且开口有拉大的趋势，这时候有可能会走出一段行情（向上或向下）。这里的经验是，通常这种单边行情的走出，是贴着布林上下轨道走的，不会大幅偏离上轨道或下轨道。当然，如果我们观测到股价开始离开布林上轨道或者下轨道，说明这段行情可能需要休息一下了。

在做趋势的时候，还有一种做法，就是以布林中轨为支撑或阻力，做多者中轨开仓，价格运行至到上轨平仓。做空者中轨开仓，价格运行至下轨平仓。

### 2.1.3 用法三：反转行情操作

根据布林线的原理，95%的概率股价会在布林线的上下轨道内运作。也就是说，如果股价大幅升破上轨，或者大幅跌破下轨，很有可能在短期内反转，重新回到轨道内。

因此这种做法需要在超出布林线上轨时做空，超出布林线下轨时做多。抓短期的超卖超买反转。在这里我的经验是，这种做法胜率很高，但是如果遇到一段单边行情的开启，例如股价跌破布林下轨道，然后稍微反弹，就继续沿着下轨道走，按照上面说的，跌破下轨做多，就会亏钱了。因此，经验上我们还需要判断布林的开口情况，如果被大幅拉开，则不太适合做反转，如果股价超过布林轨道上下轨但整体布林通道并没有呈现开口扩大的态势，这种图形的概率更大。

在布林线这里，也经常有朋友问我，像A股市场上很多一字板连板的，通常都是在布林线之外连续跑，布林线是不是就没用了？是的，布林线不适合做连续一字板的行情。但是我个人也并不去追求这种行情（曾经做打板被套的很惨），我也不建议散户朋友去做这种打板行情，不是长期可持续的。而且很多时候连着几个板突然给你停牌，欲哭无泪。

## 2.2 关键纪律：止盈止损的执行

上述就是我自己利用布林线进行买点卖点选择的经验做法。当然，如果你仅仅依赖布林线，你会被市场教育的很惨。在实战中，布林线仅仅是我进行股票投资的其中一个参考而已，实战中我会将布林线和其他指标例如RSI一起结合，比如看到布林大幅跌破下轨道，同时RSI显示超卖区间，可能是一个不错的买点，又比如将布林线和基本面的估值分析做结合来判断，等等。

在利用技术指标的时候，千万注意，做好止盈止损的交易纪律，并严格执行。先说止损，我个人的止损位置是6%，如果我建仓一只票，这只票的持仓盈亏达到-6%，我会果断离场（有一些我觉得特别有前景的票会给到大一些，例如10%的止损位置）。止损一定要果断，别后悔。我见过太多从亏6%，稍微等一等到亏10%，再等一等亏15%，开始躺平，亏损持续扩大，被迫长持（被套）的案例。散户的最大幻觉就是：跌到位了吧？应该会反弹了吧？

止损果断一点没错，但止盈可以犹豫一些。我自己在止损上习惯一键清仓，但止盈我是分批止盈。例如这家公司，在上涨过程中，每次超过布林线上轨，我就止盈一部分。当然，有朋友会想说，从结果上来看，我这种做法，实际是减少利润的，如果不止盈一直拿着，收益会更高。

是的，但问题是，这是后验的视角，在进行止盈动作的那一刻，并不知道后续会继续上涨还是下跌。同时，散户的第二大幻觉就是：高处不胜寒，稍微涨涨就拿不住全卖掉了，这就是我们说的卖飞。分批止盈有一个好处，每一次止盈一部分时，证券软件中的"持仓成本"会被摊薄，在视觉上能让我们更加安心，这种情况下，更有可能实现长持。

简单来说，果断止损，分批止盈，背后的逻辑就是：永不被套，尽量不卖飞。

# 三、基本面分析篇：看透表象看企业内在价值

基本面分析是一种评估证券"内在价值"的方法。它的核心假设是：股价短期内会波动，但长期来看，它最终一定会回归到公司的真实价值。

那么问题来了，怎么找到公司的"价值"？

对于小白入门基本面分析，我建议掌握两个角度即可。一个是商业模式，另一个是财报基本面。商业模式很简单，就是在了解一家公司的时候，问自己这么几个问题：

1. 这家公司是卖什么的？客户画像如何？
2. 这家公司是否具备独特的竞争优势？
3. 这家公司的业务赚不赚钱？是赚辛苦钱，还是躺着赚钱？
4. 这家公司的业务是否具备可持续性？

用上述问题，审视一下自己持仓的企业，对于一家公司是否值得长期持有，你就心里有数了。

## 3.1 财报分析核心：四大类关键指标

如果要做详细的投资研究，确实需要深挖财报。但对于绝大部分普通投资者，读财报更简洁的方式是跳过复杂的报表原文，直接看财务指标的变化。

财务指标有四大类：

1. **盈利指标**：看公司赚不赚钱
2. **营运指标**：看公司管理效率高不高
3. **偿债指标**：看现金流安全情况和债务压力
4. **估值指标**：看公司现在的估值是否合理

### 3.1.1 盈利指标：核心看利润率与ROE

盈利指标最典型的就是毛利率、经营利润率、净利率和ROE。一家企业从收入到利润，我们可以简化成这样的公式来理解：

- 营收 - 生产成本 = 毛利
- 毛利 - 营运成本（营销、行政、研发）= 经营利润
- 经营利润 - 利息 - 税 = 净利润

合并起来看就是：营收 - 生产成本 - 营运成本 - 利息 - 税 = 净利润

> *当然这个是简化后的利润表，学术上不严谨，但方便小白理解。*

毛利、经营利润、净利润反应的就是不同阶段的企业利润。但是由于不同企业之间的规模不一样，绝对值就不可比。例如，A公司利润100万，B公司利润1000万，能说B公司就一定比A公司更能赚钱吗？显然不能。如果我告诉你，A公司收入300万，B公司收入10个亿呢？B公司10个亿一年才产生1000万的利润，还不如存银行。

所以，为了让财报指标在不同企业间可以横向比较，我们需要把绝对值转化成每单位营收对应的利润，因此就有了各种利润率。

利润率的看法也很简单，横向比较下，比同行来的更高则好。纵向比较（自己和自己比）下，利润率趋势向上，边际向好也是好公司的特征。

ROE是个好东西，巴菲特说，如果只能看一个指标，他会选择看ROE。足以见得这个指标有多重要。ROE=净利润/股东权益，分母的股东权益是股东在这家公司投入的钱，净利润是产生的利润。是一个衡量企业为股东创造回报的直接指标。

什么是好的ROE，第一稳定，第二增长。在量化投资中，ROE可以说是最重要的质量因子了。做价值投资的人希望找到ROE稳定且高（一般高于20%）的企业。做成投股的人希望找到ROE虽然低但是边际增长迅猛的企业。

### 3.1.2 营运指标：评估企业管理效率

营运指标主要考察的是企业的管理效率。同一家公司，不同的人管理的结果天差地别。例如狼性的，灵活的，效率可能会高一些。更重视流程、制度的，效率可能会低一些。常用的营运指标有存货周转率、应收账款周转率、应付账款周转率。

**存货周转率**衡量企业卖货的速度。存货周转率=营业成本/平均存货余额。在看存货周转的时候，要结合业务来思考，如果你是卖生鲜的，存货周转率必须很高，否则菜烂了就亏了。如果你是卖豪车的，周转率低一点没关系，因为单价高。一般快消品（如饮料、零食）更重视存货周转率，而奢侈品、房地产、重工业这类行业存货周转率就低一些。

**应收账款周转率**衡量企业收钱的速度。也就是卖了货之后，过多久能把钱拿回来。应收账款周转率（次数）=营业收入/平均应收账款余额。现实社会中的商业是赊销模式，也就是先发货后付款。公司把货赊销给客户了，客户欠你的钱什么时候还？这个指标就是看你催收能力强不强。这个指标越高，说明回款快，坏账风险小，资金回笼快，企业现金流健康。

**应付账款周转率**衡量企业付钱给供应商的速度。也就是你欠供应商的钱，多久还一次。应付账款周转率（次数）=营业成本/平均应付账款余额。付款的速度快慢是企业占用供应商资金的能力。比如京东或沃尔玛，由于规模大，它们可以很长时间不给供应商结账，这相当于供应商在免费借钱给京东用。因此，这个指标和前两个营运指标有所不同，通常是越小越好，越小，付款越慢，说明供应链地位越强。

### 3.1.3 偿债指标：判断企业现金流安全

偿债指标又可以分成流动性指标和负债率两大代表，分别衡量企业的短期资金链安全情况和长期债务压力。

**流动性指标**最具代表性的就是流动比，计算公式：流动比=流动资产/流动负债。流动资产通常指现金、现金等价物及一年内可以变现的资产，流动负债就是一年内要偿还的负债。所以这个指标看的就是企业在一年内是否有现金流断裂的风险。指标大于一，说明短期安全，指标小于一，说明有现金流断裂的风险。

**负债率**就是字面意思。但问题是很多朋友对负债天然的会觉得是贬义词。其实对企业来说，负债并不一定是坏事情，适度的负债有助于发展扩张，过度的负债才会导致严重的财务压力。怎么样算适度？跟同行比较。每个行业的适度负债水平都不同，如果行业普遍都是60%的负债率，而你关注的企业达到了80%的负债率，这就有点危险了。

### 3.1.4 估值指标：核心看懂市盈率

这里我们最常用的就是市盈率、市销率、市净率。但对入门小白来说，搞懂市盈率，是最重要的。市销率和市净率的用法和市盈率是类似的，因此文中我只阐述市盈率。

市盈率的公式：股价/每股收益。每股收益就是净利润除以公司的股份数，大家可以理解成每一股的净利润。所以这个指标的分子就是当前的价格，分母是你买的企业的"质量"。我们更希望用便宜的价格买入好东西，因此在买入时，市盈率越低越好。而市盈率越高时，就说明当下可能明显高估了，是卖出的时机。

## 3.2 基本面分析的辩证应用

简单总结一下，商业模式的连环拷问，是考察你所关注的企业你是否对其生意有基本的了解，巴菲特说不熟不做，段永平说买股票就是买公司，就是这个道理。但在这里我多说一句。对于自己不懂的公司，是不是就真的严格不碰，严守自己的能力圈呢？我觉得不一定，对于不懂的商业模式，其实也可以多花时间去研究研究，让自己从不懂变成懂。以往这个过程很复杂很漫长，但在AI时代，这个过程变得便捷许多。再者就是财报的四大类指标，这四大类指标是我们去筛选长期投资的标的重要的指标，其实当你筛选出来这四方面都优秀的企业，大概率是可以长持的，就像段永平不担心他手头的某白酒公司一样，那家公司的财报指标在这四方面都是典范。但，我们辩证的思考一下，是不是这四方面指标不行的企业就不具备交易的价值呢？我觉得不一定，有时候抓一些景气成长赛道，许多成长型的企业都还在萌芽阶段，财务当然不好看了。因此，我前面特别强调了，长持的企业筛选可以多看基本面，短期交易的标的，这块就不用那么严格。

# 四、宏观分析篇：把握周期与资产配置方向

宏大叙事是散户朋友最喜欢看的主题。人生发财靠康波的旁白音在每一位散户朋友的心底无时无刻地回响。周期的判断，就是宏观分析的衍生。因本文定位主要是辅助小白朋友入门，我只会讲解最基础的宏观分析思路。对于周期的判断方法论，在最后工具篇章我会推荐一些自学的书籍，又或者将来我可以专门写一篇长文来论述周期的力量。

宏观分析最基本的就是要搞懂什么样的宏观周期下该投资什么样的资产。在这里我将介绍两种宏观分析的框架，一个是美林投资时钟，另一个是货币信用框架。

## 4.1 框架一：美林投资时钟

美林投资时钟是最经典、最易理解的宏观框架，逻辑特别简单：根据"经济增长"和"通胀水平"两个维度，把经济周期分成四个阶段，每个阶段对应着最适合配置的资产。就像我们看天气穿衣一样，不同季节穿不同衣服，不同经济周期配不同资产。

首先我们要先搞懂两个核心判断标准：

1. **经济增长**：看GDP增速（季度更新一次）或者工业增加值（月度更新一次），简单说就是"经济好不好、企业赚钱难不难"；
2. **通胀水平**：看CPI（居民消费价格指数，月度更新一次），"物价涨不涨、钱值不值钱"。

根据经济和通胀情况，我们可以分成四个阶段：

1. **复苏期**：经济向好，物价不涨
2. **过热期**：经济向好，物价也涨
3. **滞胀期**：经济变差，物价继续涨
4. **衰退期**：经济变差，物价不涨

### 4.1.1 各阶段特征与资产配置

**复苏期**（经济向好，物价不涨）的核心特征是经济从低谷慢慢爬起来，企业开始赚钱，但是物价还没涨起来（通胀低）。比如大家敢花钱消费了，企业订单变多了，但菜市场的菜价、超市的零食价还没怎么动。这种状态股票的表现会相对其他资产类别更好，因为这时候企业盈利在改善，而且央行通常会保持宽松的货币政策（比如降息），钱变多且便宜，容易推动股市上涨。

**过热期**（经济向好，物价也涨）的特性就是经济活力拉满，企业赚钱效应特别好，但物价也开始快速上涨（通胀高）。比如工地到处都是开工的，工厂加班赶订单，同时大家发现买菜、加油都变贵了。大宗商品（比如原油、煤炭、有色金属）通常是这种阶段表现较好的资产类别。通胀的时候，原材料价格会跟着涨，持有大宗商品能直接享受涨价红利。这个阶段股票也能涨，但要注意央行可能会加息（收紧钱袋子），随时会冲击股市。

**滞胀期**（经济变差，物价继续涨）是最难受的周期。经济增长变慢甚至下滑，但物价还在涨（手头的钱购买力下降）。大家找工作变难了，工资没涨，但吃饭、租房的成本还在上升。这时候持有现金及现金类资产（比如货币基金、活期存款）是明智的选择，这个阶段是"股债双杀"，股票因为企业盈利差下跌，债券因为通胀可能被加息压制，所以最稳妥的就是持有现金，保住本金等待机会。

**衰退期**（经济变差，物价不涨）指的就是经济增长持续下滑，物价也开始下跌（甚至出现通缩，钱越来越值钱但大家不敢花）。比如企业开始裁员、倒闭，大家觉得未来赚钱难，宁愿把钱存起来也不消费、不投资。债券在这时更加适合，因为这时候央行会出台宽松政策救市，比如降息、降准，债券价格就会上涨（债券价格和利率成反比）。

## 4.2 框架二：货币信用框架

货币信用框架就是看钱的流动情况，毕竟不管经济好不好，投资最终还是得有流动性的推动。这个框架对中国市场更加实用，因为我们经常会遇到央行放水了，但经济还是没起来的情况，用这个框架就能解释清楚。

先搞懂两个核心概念：货币和信用。

**货币**：指的就是市场上钱多钱少，核心看央行的动作和货币供应量，代表指标是M2（广义货币供应量，月度更新一次）和存款准备金率。比如央行降准、降息，就是"宽货币"（水龙头开大）；加息、提准就是"紧货币"（水龙头关小）。

**信用**：指放出来的钱有没有被实体经济用起来，核心看社会融资规模（简称"社融"，月度更新一次）和新增人民币贷款。简单说就是"水有没有流到田里（企业、居民、政府）"，比如企业愿意借钱扩产、居民愿意借钱买房，就是"宽信用"（资金成功流入经济）；企业不敢借钱、居民不敢贷款，就是"紧信用"（虽然看起来市场上很多钱，但无法流进实体经济，产生流动性陷阱）。

货币信用框架的核心就是把"货币"和"信用"分成"松/紧"两个维度，组合成四个场景，每个场景对应不同的资产选择：

1. **宽货币 + 宽信用**：这个是经济复苏的黄金阶段，央行放水（宽货币），而且企业、居民愿意借钱花钱（宽信用），钱真正流到了实体经济里。这时候经济会慢慢复苏，企业盈利改善，是最健康的经济状态。股票在这种货币信用状态下最合适，因为这时候流动性充裕，企业盈利好转，容易迎来普涨行情，成长股、周期股都有机会。

2. **宽货币 + 紧信用**：我们也叫经济磨底，或者叫流动性陷阱。举个例子，央行放水了（宽货币），但大家对未来没信心，企业不敢借钱扩产，居民不敢借钱消费（紧信用），放出来的钱都趴在银行，没进入实体经济。这是我们过去几年经常出现的情况。这种状态下适合债券、黄金、高股息股票。因为钱没地方去，就会流向具备避险属性或防御属性的资产。

3. **紧货币 + 宽信用**：经济过热，政策收紧是这个阶段的特征。这时候经济增长快，企业、居民借钱意愿强（宽信用），但因为通胀太高，央行开始收紧货币（加息、提准），防止经济过热。和美林时钟的"过热期"对应。大宗商品在这种阶段相对表现会更好，通胀上行推动大宗商品涨价。债券会因为加息下跌，要避开。

4. **紧货币 + 紧信用**：最恐怖的阶段，经济下行叠加政策收缩。央行收紧货币，同时实体经济借钱意愿弱，经济增长下滑。这是最危险的阶段，企业盈利差，市场流动性紧张。和美林时钟的"滞胀期"或"衰退期"后期对应。这种时候，就持有现金及现金类资产吧，等待政策宽松的信号出现再出手。
