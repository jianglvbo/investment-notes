# 稳定币赛道分析框架

## 适用场景

分析稳定币发行方（如Circle/USDC、Tether/USDT）的商业模式、竞争格局和投资价值。适用于评估"吃利息+转型基础设施"的混合型金融科技公司。

## 方法步骤

1. **拆解收入结构（三层法）**：
- 第一层：利息收入（储备投资国债/货币市场的收益）——当前赚钱方式
- 第二层：交易/支付收入（跨境结算、跨链转账等）——增长新业务
- 第三层：平台收入（区块链网络手续费等）——长期可能性
- 关注各层收入占比变化趋势
2. **竞争格局分析（双维度）**：
- 流通量对比（市场份额）
- 交易量/流速对比（实际使用程度 vs 被持有程度）
- 用户定位差异（合规机构 vs 加密原生/新兴市场）
3. **分成协议与议价能力**：
- 核心合作方的分成结构
- 协议到期时间与续约预期
- 增量业务是否在合作方平台之外（降低依赖度）
4. **估值框架选择**：
- 利率敏感金融公司 → 10-15x PE
- 支付基础设施公司 → 25-35x PE
- 科技平台公司 → 更高倍数
- 关键判断：公司正在从哪个框架向哪个框架迁移

## 关键指标

- 稳定币流通量（每日可查，判断增长趋势）
- Visa调整后链上交易占比（判断是被使用还是被持有）
- 非利息收入占比（>10%时市场估值方法可能切换）
- 储备收益率（反映利率环境）
- 合作方分成比例变化

## 案例

Circle（CRCL）：USDC发行方，95%收入来自利息，受Coinbase分成制约。2026年8月协议到期后议价能力改善。CPN跨境结算和CCTP跨链协议是摆脱"利率公司"标签的关键。市场估值在100美元附近，分析师目标价60-243美元分歧巨大。
