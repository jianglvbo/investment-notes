# 询问三宝分析法：识别优质公司

## 适用场景

识别"优质公司"——不找最耀眼的公司（苹果/英伟达/微软），而是找到**时间能站在它一边**的那一家。适用于从零评估一家公司是否值得长期投资，尤其适合挖掘"不起眼但不可替代"的公司（如工业气体生产商——芯片厂/钢铁厂/医院离不开，却没有互联网、没有 AI、没有流量）。

## 方法步骤

**一问：它是不是在解决一个越来越大的问题？**
问题越大 = 有市场、有经济效益，是一切研究分析的起点。注意"刚需"≠"好生意"：
- **反例·煤炭**：刚需但产品高度同质化、无定价权，利润完全由市场需求决定，未必是好生意
- **反例·烟草**：现金流极丰厚但受政策和法律双重打击（英国立法 2009 年后出生者终身禁烟、香港严格禁烟措施）——**企业最大的风险不仅来自竞争对手，还来自时代本身**
- **环境土壤差异**：同一商业模式不同地区结果不同（外卖在中国跑出万亿巨头，美国因居住分散/小费文化跑得慢）——人口结构与社会文化是关键变量

**二问：你的生意，别人到底抢不抢得走？**
把利润从 1 亿做到 2 亿只有四种方式：拉新、复购、提价、降本——所有商业模式本质都围绕这四件事，要做到必须有**护城河**：
- **类型一·极致成本结构**：蜜雪冰城（自建柠檬园、自产糖浆，4 元柠檬水无人能打价格战）；美国西南航空（只用一种机型、只做超短途，商业结构决定永远可以更便宜）
- **类型二·品牌拥有定价权**：苹果（生态迁移成本高）、爱马仕（身份地位彰显）
- **类型三·小市场垄断**：太空笔（全球市场几千万美元，大公司不屑做、新进入者投入产出比不划算，但细分领域非它不可）

**三问：你的收益质量如何？**
用财报两条标准检验：
- **标准一·蠢人经营法**：换一个刚毕业、啥也不懂的 CEO，三年后公司会不会江河日下？不会 → 生意惯性极强（通常不出现在科技公司，因科技公司更新换代快、对经理人期待高）
- **标准二·自由现金流**：净利润能被拿走多少？明年还需不需要继续投入同样的生产/设备/营销才能维持？**能被拿走的越多，护城河就越深**（蜜雪加盟费、太空笔都是这种钱）。优质公司是持续生钱的**现金牛**，不是不断输血的**吞金兽**

## 关键指标

| 维度 | 判断标准 |
|:---|:---|
| 问题大小 | 市场空间 + 经济效益（区分"刚需"与"好生意"） |
| 护城河 | 成本结构 / 品牌定价权 / 小市场垄断，三选一即强 |
| 收益质量 | 蠢人经营法（换 CEO 三年不垮）+ 自由现金流（可拿走越多越好） |
| 时代风险 | 政策/法律/技术变革是否正在消灭市场（烟草教训） |

## 案例

- 对应经典框架：**PESTEL 分析法**（政治/经济/社会/技术/环境/法律——英国禁烟=政治法律、中美外卖=社会、AI 冲击=颠覆型技术）+ **波特五力模型**（行业内竞争/潜在进入者/替代品/客户溢价/供应商溢价——iPhone 淘汰功能机=替代品、存储芯片涨价=供应商溢价）
- 蜜雪冰城、西南航空（成本护城河）、苹果、爱马仕（品牌定价权）、太空笔（小市场垄断）、工业气体公司（不可替代的"隐形冠军"）
