# 研报六问拆解法

> 核心判断：卖方研报天生偏多——券商要靠上市公司吃饭，写"卖出"以后调研、演讲都没了。所以结论不重要，得出结论的逻辑才重要。必须自己把结论往回拨到假设层。

## 适用场景

面对一份券商研报——尤其是"强烈推荐""买入"评级满天飞的时候——用它来判断这份报告能信几分。看图表比看文字有用，看数据比看观点有用。

## 方法步骤

**第一问：谁写的，写给谁看的？**
卖方报告找它"没说什么"；买方报告多看决策逻辑（为什么在这个时点、这个价位觉得值）；行业报告看框架和空间测算就行，个股建议不用太当真。

**第二问：核心逻辑能不能一句话讲清楚？**
看完研报都不知道它到底看好什么，要么是水平不够，要么是报告自己也没想明白。好的逻辑一定简单清晰，比如"受益于国产替代，市占率从5%提升到20%"。关键要区分**事实驱动**（已发生的变化：政策落地、产能释放、订单拿到）和**故事驱动**（可能会发生：AI赋能、元宇宙、低空经济）——后者10个有9个是画饼。

**第三问：盈利预测靠谱吗？**
拿报告的预测比三个东西：公司过去三年平均增速、行业平均增速、投行预测增速。如果报告预测明年增长50%，但过去三年平均才15%、行业平均10%，那50%怎么来的？能解释清楚（新产能投产、新客户放量）还可以信；啥也没解释就画了个陡峭曲线——你懂的。

**第四问：估值合理吗？**
市盈率、市净率、市销率分两个维度看：当前处在历史什么分位？和同行比贵不贵？现在市盈率80倍、历史最高60倍——比历史任何时候都贵，这时有人说"合理估值"，得打个问号。估值不能只看一个指标：互联网和成长公司看市盈率没用，得看市销率（PS）、市研率；重资产公司市盈率不如市净率好使。

**第五问：风险提示是认真的吗？**
翻到研报最后的风险提示段。如果通篇都是"宏观经济下行、行业竞争加剧、政策不确定性"，这就是套话，啥也没说。真正有水平的风险提示会写具体的量化情景，例如"若海外大客户订单削减20%，净利润将减少3亿"。套话式风险提示说明分析师自己都没认真想风险。

**第六问：催化剂和时间线清晰吗？**
长期看好≠短期能涨。好公司没有催化剂可能趴三年。研报里必须说清楚：什么事件在什么时间能兑现？是新产品发布？政策落地？还是产能释放？没有时间表的推荐，等于没有推荐。

**进阶：多份研报交叉对比。** 同一家公司同时看至少三家券商的报告。三家预测高度一致，要么是市场共识正确，要么是集体跟着领导跑；分歧很大时，分歧点才是真正值得研究的地方。**一致预期最危险**——2015年所有人都说创业板涨到一万点没问题，结果集体误判比个人误判杀伤率大一万倍。

## 关键指标

| 维度 | 检验问题 | 危险信号 |
|:---|:---|:---|
| 逻辑 | 事实驱动还是故事驱动 | 故事驱动（AI赋能/元宇宙/低空经济） |
| 预测 | 三重对照（历史/行业/投行） | 远超历史和行业增速却无解释 |
| 估值 | 历史分位 + 同行对比 | 比历史任何时候都贵还说"合理" |
| 风险 | 套话还是量化情景 | 通篇"宏观下行、竞争加剧"套话 |
| 催化 | 有无明确时间表 | 只说"长期看好"无事件驱动 |

## 行业黑话解码

| 黑话 | 人话 |
|:---|:---|
| 业绩符合预期 | 没惊喜也不算惊吓，预期本来就不高 |
| 短期承压 | 现在出问题了，多严重不敢说 |
| 静待花开 | 现在确实不行，啥事能行我也不确定 |
| 估值处于历史底部 | 确实便宜，但为啥这么便宜不方便展开 |
| 建议重点关注 | 不敢明着说让你买，但希望涨了你能想起我 |
| 下调盈利预测，维持买入评级 | 之前吹过了现在往回找补，又不能自己打脸 |
| 公司处于转型阵痛期 | 新业务没赚钱，老业务在下滑，两头不靠 |
| 积极布局新兴赛道 | 主营不太行了再找新方向，能不能成先投了再说 |

## 案例

**某消费电子公司的崩塌**：2023年好几家券商发深度研报，核心逻辑都是"新品放量、业绩爆发"，目标价给得高、评级全是"买入"。只看研报会觉得是十倍股。财报出来后看三个数据：收入增长25%（看起来不错）；应收账款增长80%（远超营收增速——增长是赊销堆出来的）；经营现金流是负的（号称爆发式增长的公司现金流在恶化）。结论：利润表的增长是假增长。后来股价跌了60%，看研报冲进去的人全套在山顶。

---

- 卖方研报天生偏多，必须把结论往回拨到假设层——结论不重要，逻辑才重要
- 事实驱动 vs 故事驱动是判断逻辑质量的分水岭
- 一致预期最危险：集体误判比个人误判杀伤力大得多
- 研报"不说的东西"往往比说的更重要——避而不谈的竞争对手降价、大客户流失、政策变数，可能就是真正的风险
