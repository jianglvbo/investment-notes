# 猪周期产能出清困境

## 行业概况

生猪养殖行业全行业亏损（2025年4月每头大肥猪亏损约400元，6月仍亏340元），但在"反内卷"政策下，各大企业非但没有减产，反而暗中增产，试图以产能优势卷死对手。行业处于存量博弈状态，龙头无法打出真正差异化。

## 关键数据

| 指标 | 数据 | 说明 |
|:---|:---|:---|
| 每头肥猪亏损 | 340-400元 | 2025年4-6月 |
| 能繁母猪减少 | 3.3% | 表面减产 |
| 母猪产仔数提升 | 21头->26头（头部30头） | 效率提升抵消数量减少 |
| 等效产能 | 3900万头母猪 约等于 过去4500万头+ | 实际产能未缩减 |
| 出栏体重目标 | 120公斤 | 政策要求 |
| 实际出栏体重 | 123公斤（6月） | 4亿头猪x3公斤=12万吨超额猪肉 |
| 产销率 | Q1 83.5% -> 80% | 需求疲软 |
| 生猪存栏 | 同比降、环比增 | 老实人减产，不老实的偷偷扩产 |

## 时间线

| 时间 | 事件/数据 | 涉及个股 |
|:---|:---|:---|
| 2025年4月 | 每头大肥猪亏损约400元 | 养殖板块 |
| 2025年6月 | 亏损缩至340元，出栏均重勉强降至123公斤 | 养殖板块 |
| 2025年Q1 | 生猪存栏不减反增，反内卷政策效果甚微 | 养殖板块 |

## 核心逻辑

1. **效率提升抵消数量减产**：母猪少了但产仔数提升，实际供应能力未降
2. **在建工程转移而非消失**：资金从新建猪场转向屠宰厂、饲料厂，为下一轮扩产准备
3. **大企业靠期货套保续命**：一边养猪一边做空猪价，小企业难以承受长期亏损
4. **养殖业造假风险高**：獐子岛、雏鹰农牧等历史案例，财报数据需谨慎对待[^supplement-2][^supplement-1]
5. **产能出清速度比新能源、房地产快，但仍在想方设法扩产**
