# 估值路径依赖与流动性盲区

## 背景

2026年中，恒生科技较去年高点-30%，中概软件回撤约40%。[^supplement-1]核心成分股如腾讯、阿里跌了30%，B站、小米、美团等50-60%回撤。一位经典基本面价投选手满仓回撤接近40%，年内收益率回撤接近-18%。

## 经验教训

## 1. 站在能力圈内

- 超额收益来自能力圈内持仓公司的利润和成长性不断兑现
- 持仓风格集中，好公司只要不贵就一直持有
- 靠短期波动加减仓增厚收益，属于经典基本面价投

## 2. 接受外界因子给收益带来的变化

- 持仓公司只是估值在压缩，基本面并没有受到影响
- 很多时候需要接受外界因子（流动性、风险偏好等）给收益带来的变化
- 不因数字变化而苛责自己

## 3. 估值路径依赖的盲区

- 基本面价投选手容易过度关注公司利润和成长性，忽视流动性和风险偏好等外部因子对估值的巨大影响
- 在港股等离岸市场，流动性因子对估值的影响可能远超基本面变化

## 4. 投资与生活的平衡

- 没有客户压力、家人支持的情况下，为数字变化而苛责自己是不聪明的做法
- 投资是为生活服务的，不应让投资焦虑侵蚀生活质量

## 借鉴意义

- 基本面分析不能忽视流动性和风险偏好等外部因子
- 估值压缩不等于基本面恶化，需要区分
- 投资复盘不应只关注操作对错，也要接受不可控因子的影响
