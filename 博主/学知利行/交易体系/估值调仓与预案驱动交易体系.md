# 估值调仓与预案驱动交易体系

**核心：不预测后市，以持仓估值水平为调仓锚，按预设预案执行买卖，无机会不勉强。**

## 规则

1. **估值锚调仓**：根据持仓标的的估值水平动态调整仓位——估值偏高时减仓，估值达到舒适折扣时加仓

2. **预案驱动**：所有操作提前规划，按预案执行而非临时决策

3. **买入纪律**：新买入标的必须达到舒适的买入估值折扣水平才会下手

4. **不勉强**：没看到机会也不会勉强买入，宁可持有现金等待

5. **现金管理**：闲余资金用于货币基金和北交所打新等低风险增强。北交所打新不可能是资金的目标，收益太低，就比货币基金高一些，好处是两天之内就可以使用现金，是货币基金的替代品；手握现金，只是等待合适的买入机会

6. **回补价格在卖出时就定了**：回补（买回）价格在卖出时就已确定，只是还没到；估值不会三天两头变（如藏格这种公司，分红在估值中的比重很小），很多人把自己的预期当估值了——**预期不是估值**，回补决策只看估值锚而非情绪

7. **不博弈**：认为价格合适就买入；博弈的结果很可能是"预期你的预期"被戏耍，除非在这方面能力出众，否则直接认怂

### 动态仓位管理操作（并入 2026-08-01 条目）

**冲高减仓**：在持仓（如长江电力、华能水电）冲高过程中进行部分减仓，把现金仓位恢复到 10% 以上，应变能力随之提高。不去猜想市场后面是一枝独秀、艳阳普照还是泥沙俱下，只考虑如何应对。

**创新低加仓**：给机会一定要用——对股价阶段性创新低的持仓适当加仓，买入更低估、更有成长潜力的标的。市场给的机会要不断用来调整仓位。

**底层信念**：从未来三到五年的中期看，相信这些公司的未来收益支撑的合理市值应该会给股东一个合理的回报。

**风险边界**：若标的基本面恶化，"创新低加仓"会变成接飞刀——前提是标的本身基本面扎实、未来三到五年收益可支撑合理市值。

## 适用条件

- 适用于震荡市或结构性行情，持仓标的有明确估值锚且能跟踪现金流

- 需要投资者对持仓标的的合理估值有独立判断能力

## 不适用条件

- 单边牛市或黑天鹅事件导致的流动性危机中，可能错过大幅上涨或承受超预期回撤
