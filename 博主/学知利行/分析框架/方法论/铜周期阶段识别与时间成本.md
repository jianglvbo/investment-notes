# 铜周期阶段识别与时间成本

**核心判断：铜周期中股价顶、投资顶与铜价顶并不同步——上一轮周期里 A 股股价 2007 年到顶、2011 年反弹顶、2012 年全球铜矿投资额到顶后铜价暴跌，至 2014 年紫金矿业跌了约 90%；周期行业最怕错过投产时间，时间是有成本的。**

## 适用场景

判断铜（及类似强周期金属）行业所处周期阶段、评估周期股投资时机，尤其是"新产能投产对估值是否有意义"的问题。

## 方法步骤

1. **分清三个"顶"的次序**：股价顶 → 投资额顶 → 商品价顶。上一轮铜周期：相关公司 A 股股价在 2007 年到顶，后到 2011 年有个反弹顶（但离 2007 年的顶差距比较大）；2012 年全球铜矿投资额到顶，铜价开始暴跌；至 2014 年紫金矿业差不多跌了 90%
2. **警惕"新产能护估值"的幻觉**：这期间新的产能对公司估值没多大意义——周期下行段里，产量增长抵消不了价格崩塌，估值随价格走
3. **尊重周期的不可抗性**："愿望是一回事，周期就是周期"——多品种错位（金铜锂不同步）、产量上升稳业绩等说法，都无法改变周期下行段的估值杀伤力
4. **把时间成本算进去**：时间是有成本的，特别是对周期性强的行业，错过了好的投产时间是个很麻烦的事（例子：藏格当年为什么以那么低的价格把巨龙控制权转给紫金，了解了整个过程就知道在行业低迷期做一件事有多难）

## 关键指标

- 全球铜矿资本开支/投资额（投资顶的领先信号）
- A 股周期股股价相对商品价的领先/滞后关系
- 具体公司的投产时间表（如三期项目）与商品价格周期错配程度

## 案例

- 上一轮铜周期（2007-2014）：股价顶 2007 → 反弹顶 2011 → 投资额顶 2012 → 铜价暴跌 → 2014 年紫金矿业较顶部跌约 90%
- 紫金矿业(601899)、藏格矿业(000408) 为本方法论的持续跟踪对象
