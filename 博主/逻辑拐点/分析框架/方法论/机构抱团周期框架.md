# 机构抱团周期框架

## 适用场景

判断当前市场最强板块的抱团处于什么阶段（形成/加速/假摔/瓦解），决定是否跟随、持有还是撤离。适用于任何以业绩驱动的趋势性行情。

## 方法步骤

**第一步：识别最强业绩板块，快速参与抱团。** 机构永远青睐业绩增速最快的板块，不是某个特定板块。及时识别最强业绩板块、最快速参与抱团，是最佳选择。

**第二步：区分假摔与真瓦解。** 抱团往往会有1-2次假摔。放弃前先问灵魂之问："业绩趋势破坏了吗？"每次假摔后抱团更坚定，超额收益假摔后是加速上行的。一轮趋势一般能持续13个季度甚至更长——所以拉长对基金经理的考核反而有助业绩。

**第三步：识别后期信号。** 抱团到了后期，会给投资者以"该板块永远会涨、永远会跑赢"的信念。这种信念会以不同的简单明了上口的概念体现。"躺着赚钱这么简单为什么要调仓？"——这种理念会让在抱团最后减持的投资者痛苦不已：如果跑，会不会又重新抱回来？如果不跑大家都在跑怎么办。

**第四步：判断真瓦解。** 每次抱团瓦解的根本原因，是出现了业绩更好的板块，不是"太贵了"。估值、拥挤度、政策冲击这些是触发或催化，但根因永远是业绩比较优势的转移。当炙手可热、朗朗上口、完美无缺的概念取代"业绩-估值"框架流行时，要打起十二分精神。一个板块不需要研究就能赚钱的时候，恰恰是危险信号。趋势拐点常伴随从未出现过的新事物/新现象——正向反向都可能，出现"没听说过的事"时警惕。

**第五步：不要左侧逆风买抱团瓦解的板块。** "根本没人看"才是真抛弃，不是"大家说不看好"。

## 关键指标

| 指标 | 用途 | 备注 |
|:---|:---|:---|
| 业绩增速比较优势 | 判断抱团根基 | 唯一灵魂之问："业绩趋势破了没有？" |
| 抱团持续季度数 | 判断所处阶段 | 一般13个季度甚至更长 |
| 叙事替代估值的程度 | 后期过热信号 | 概念取代业绩-估值框架 |
| 是否出现"没听说过的事" | 拐点预警 | 正向反向都可能 |
| 板块关注度 | 判断是否真抛弃 | "根本没人看"才是真抛弃 |
