# 产能过剩周期中游制造的利润挤压逻辑

## 适用场景

分析中游制造/代工企业（纺织、电子代工等）在行业产能过剩周期中的利润表现。用于解释：为什么需求端汇率升值、成本端原材料涨价，利润却两头受压；判断企业业绩下滑的性质（周期性 vs 竞争格局恶化）。

## 方法步骤

### 一、识别两头挤压：定价权消失 + 成本转嫁失败

产能过剩的周期里，中游制造企业两头受气：

- **收入端**：已经定好的产品价格不能因为人民币升值而涨价——客户不接受，因为"你不做有别人做"；
- **成本端**：原材料涨价导致的成本上升也很难获得客户认可。

2026年8月申洲国际公布业绩预减报告，估计中期业绩下降40%左右。達人知命判断自己持有的超盈国际类似（人民币升值侵蚀利润 + 石油价格上涨推高成本），但利润降幅略好于申洲国际。

### 二、用代工行业的共同逻辑类比

達人知命以前在电子代工行业做过很久，认为两者逻辑相差不大。核心判断：**在产能过剩周期里，代工企业的盈亏不看产品竞争力，看"谁口袋深"**——比谁亏得起，能把别人熬死。

### 三、区分实业与股市投资者的处境差异

**实业老板**：没办法随意更换行业，沉没成本太多，变卖了也不值什么钱，只能慢慢熬。

**股市投资者**：可以中途换仓，只是要知道行业不景气的时候股价也跌了不少了，值不值得换而已。

### 四、用估值与现金流判断熬的价值

超盈国际最近5年最差的是2022年盈利3个亿HKD，目前市值不到24亿，也不到8PE——如果盈利底部已现，估值处于低位，那就和大股东一起坚持一下也不妨。另一个相对重仓的信邦控股走势也比较差，应该是类似逻辑。

**底线：只有验证了诚信程度的公司才能坚守。** 估值低不等于可以闭眼拿，公司是否诚信（兑现承诺、不损害股东）是坚守的前提。

## 关键指标

| 指标 | 用途 |
|:---|:---|
| 产品定价能力 | 产能过剩期定价权是否消失（"你不做有别人做"） |
| 成本转嫁能力 | 原材料涨价能否传导给客户 |
| 汇率敏感性 | 人民币升值对出口制造利润的侵蚀 |
| 现金储备/亏损承受力 | "比谁口袋深"——谁能熬死对手 |
| 盈利底部确认 | 历史最差年份盈利 + 当前市值对应PE（如超盈8PE以内） |
| 公司诚信度 | 是否值得在低谷期坚守 |

## 案例

**申洲国际(02313)**：2026年8月业绩预减约40%，人民币升值侵蚀利润+石油涨价推高成本，产能过剩周期中游制造的典型利润挤压案例。

**超盈国际(02111)**：達人知命判断业绩预减幅度略好于申洲；2022年最差盈利3亿HKD、市值不到24亿、不到8PE，与估值底部对应，判断可与大股东一起坚持。

**信邦控股(01571)**：相对重仓，近期走势较差，达人称应该是类似逻辑（电子代工/制造同源）。
