# 布林线(BOLL)三种交易战法

## 规则

## 布林线基础

- 由约翰·布林发明，利用统计学标准差构建价格波动"范围"
- 三条线：上轨道、中轨道（均线）、下轨道
- 基于正态分布，约95%的价格波动落在上下轨区间内
- 上下轨之外是小概率事件

## 战法一：震荡行情

- **条件**：布林通道走平，无催化剂
- **操作**：触达下轨做多，触达上轨做空
- **退出信号**：布林上下轨宽度突然变宽 → 震荡结束，转为趋势操作
- **风险**：震荡转趋势时不果断退出会遭受损失

## 战法二：趋势行情

- **条件**：布林结束平行震荡，开口有拉大趋势
- **向上趋势**：股价沿上轨道单边上涨
- **向下趋势**：股价沿下轨道单边下跌
- **操作**：
  - 做多者以中轨为支撑开仓，运行至上轨平仓
  - 做空者以中轨为阻力开仓，运行至下轨平仓
- **休息信号**：股价开始离开上/下轨道 → 行情可能需要休息

## 战法三：反转行情

- **条件**：股价大幅升破上轨或大幅跌破下轨
- **操作**：超出上轨时做空，超出下轨时做多，抓短期超卖超买反转
- **胜率高但需配合判断**：
  - 如果布林通道没有呈现开口扩大态势 → 反转概率更大
  - 如果布林被大幅拉开 → 不适合做反转（可能是单边行情开启）

## 交易纪律

- **止损**：6%（特别有前景的票可给到10%），果断一键清仓
- **止盈**：分批止盈，每次超过布林线上轨止盈一部分
- **核心逻辑**：果断止损 → 永不被套；分批止盈 → 尽量不卖飞
- 分批止盈额外好处：摊薄持仓成本，视觉上更安心，有助于长持

## 适用条件

- 不适合一字板连板行情
- 不建议做打板行情（不是长期可持续的）
- 需结合RSI等其他指标 + 基本面估值分析综合判断
- 纯技术分析不可依赖[^conflict-1]，需叠加基本面和宏观分析
