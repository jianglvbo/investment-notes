# 长短期投资交易框架

## 规则

## 核心原则：不必强行给自己贴标签

- 不必定义自己为长期投资者或短期交易者
- 一个人完全可以同时拥有长期投资部分和短期交易部分
- 养老钱用于长期配置，另一部分资金用于短期交易

## 长期投资：资产配置与再平衡

1. **资产配置（Asset Allocation）**
   - 股票、债券、黄金等商品 + 不同币种资产多元化配置
   - 理论支撑：多因子模型、马科维茨现代组合理论
   - 基本要求：至少做到分散化配置

2. **再平衡**
   - 根据市场变化调整仓位
   - 涨幅大、估值偏高 → 适当降低权重
   - 权重下降或更具性价比 → 适当增加配置
   - 参考信号：资产相对200日均线偏离度
   - 频率：个人通常一年做两次再平衡

## 短期交易：建立交易系统

1. **量化或技术指标**：明确关注的横截面因子或技术指标
2. **交易纪律**：提前设定止损线和止盈线[^enhance-2][^enhance-1]
3. **工具选择**：根据策略选择工具（期权、正股、期货等）
4. **交易心理**：识别并管理心理偏差（行为金融学）

## 交易复盘

- 收益拆解 + 业绩归因
- 工具：Brinson模型、多因子模型
- 从风险因子角度理解收益来源
- 判断自己暴露在哪些风险下，这些风险是否贡献了收益

## 适用条件

- 长期资金：适合养老、教育等长期目标
- 短期资金：满足交易欲望，减少对长期仓位的干扰
- 两者可并行，不互斥
