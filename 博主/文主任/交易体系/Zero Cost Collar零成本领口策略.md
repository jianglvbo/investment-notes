# Zero Cost Collar零成本领口策略

## 规则

**适用场景**：高波动环境下的期权策略，适用于热门半导体/AI硬件公司等波动较大的标的。可作为三层风控框架的第三层风控，也可单独作为收益策略使用[^enhance-1]。

**构造方法**：

1. **持有100股正股**（如美光等热门半导体/AI硬件公司，每一张期权对应100股）
2. **买入一张平值（ATM）Put**，行权价 = 建仓价，期限1个月
3. **卖出一张虚值（OTM）Call**，约4%左右的涨幅，期限同样为1个月

**波动放大后的成本优势**：由于近期波动放大，卖4%涨幅Call所得权利金基本可以Cover买入Put的成本，结构接近**"零成本"**构建。以往市场平静时往往需要寻找3个月以上期限的期权才能做出类似结构；现在波动起来，1个月就能找到大量机会。

**收益区间**：

| 情景 | 结果 |
| --- | --- |
| **最坏情况**（市场大跌） | Put行权，按建仓原价卖出，**最坏不亏钱** |
| **最好情况**（市场大涨） | 被Call封顶，**最多赚约4%/月（年化48%）** |

一个月封顶4%，年化约48%，在当前波动率环境下已是相当不错的非对称结构。

**核心逻辑**：这不是赌方向，而是构建一个**非对称收益结构**：下跌有保护，上涨有封顶但收益可观。适合"不做预测、只做应对"的交易哲学。

## 适用条件

- **高波动环境**：波动放大后期权定价有利，卖Call权利金可覆盖买Put成本
- **热门标的**：流动性好的半导体/AI硬件公司期权
- **1个月期限**：当前波动环境下1个月即可找到大量Zero Cost Collar机会
- 可作为风控层（三层风控框架第三层），也可作为独立收益策略
