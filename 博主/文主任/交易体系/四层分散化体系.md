# 四层分散化体系

## 规则

分散化是 Howard Marks 在访谈中开门见山强调的第一原则：**不要对某个单一观点押注过重**——不要全仓科技，不要全仓某个消费板块，也不要全仓白酒，最好是多资产、多因子、多类别，什么都买一点。

但散户对分散化最常见的误解是：以为买机器人和买芯片就是分散化。其实机器人加芯片都是非常集中的——都集中在高风险高收益板块。真正的分散化要从不同角度去构建。文主任自己从四个层面来做：

1. **因子层面**：价值因子与动量因子构成一定的分散化。
2. **持股数量层面**：持股数量本身构成一定的分散化。
3. **策略层面**：同时配置横截面策略与趋势跟踪类策略，构成策略层面的分散化。
4. **资产类别层面**：在股票之外加入债券、大宗商品、黄金等，构建跨资产层面的分散化。

## 适用条件

**道理简单，难在克制贪欲。** 很多人一开始也会做跨资产的多资产配置，但一看到某个板块或赛道涨得好，就忍不住减掉其他仓位、加仓到涨得好的部分。而等你发现它涨得好的时候，其实它已经涨完一轮了。这种没有成熟量化策略轮换、纯粹凭感觉的浮盈加仓，对散户非常危险。

跨资产层面的补充原则：
- **股票不建议做择时**；
- **债券信号比股票纯净很多，可以适度择时**；
- **大宗商品和黄金，要等真正研究透之后再纳入配置**——对一个资产了解透之后再加进来。

## 验证记录

跨资产层面的分散化，是文主任自述"这条视频里教会我的"——属于正在往里加、尚未完全落地的部分。
