# 市场分析五层框架：宏观→行业→公司→品类→交易

## 适用场景

构建个人对金融市场的系统性理解。从宏观到微观逐层展开，帮助投资者建立完整的分析链条。[^enhance-4][^enhance-3][^enhance-2][^enhance-1]

## 方法步骤

## 第一层：宏观经济

- 理解经济周期与政策调节
- GDP构成：投资、消费、进出口（三驾马车）+ 政府支出 + 外汇
- 定期跟踪消费、投资、进出口、外汇数据
- 政策工具：货币政策（降准、降息）+ 财政政策（财政支出、补贴）

## 第二层：行业分析

- 重点判断行业是否具备明确的空间、确定性和可量化的增长路径
- 偏好那些在时间和规模上都较为确定、可以通过数据推算的行业
- 工具：波特五力模型、PEST模型、行业集中度分析、行业生命周期模型

## 第三层：公司分析

- 核心是财报分析：
  - **资产负债表**：资产结构、负债水平、财务健康
  - **利润表**：盈利能力、盈利可持续性
  - **现金流量表**：现金流健康度、经营现金流支撑力
- 结合估值分析：绝对估值 + 相对估值

## 第四层：品类分析

- 决定具体投资什么资产：股票、债券、基金、期权、加密资产
- 不同品类的风险收益特征、定价方式和交易工具不同
- 重点理解如何给资产定价

## 第五层：投资交易执行

- 长期投资：资产配置 + 再平衡
- 短期交易：建立交易系统（指标、纪律、工具、心理）
- 交易复盘：收益拆解 + 业绩归因（Brinson模型、多因子模型）

## 关键指标

| 层次 | 核心关注 | 关键工具/指标 |
|------|----------|---------------|
| 宏观 | 经济周期、政策方向 | GDP、CPI、PMI、利率 |
| 行业 | 空间、确定性、增长路径 | 波特五力、PEST、集中度 |
| 公司 | 基本面、估值 | 三张报表、DCF、PE/PB |
| 品类 | 资产定价、风险收益 | 各类定价模型 |
| 交易 | 执行、复盘 | 交易系统、归因分析 |
