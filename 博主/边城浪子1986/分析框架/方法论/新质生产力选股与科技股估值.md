# 新质生产力选股与科技股估值

## 适用场景

- 在政策鼓励的新质生产力方向（科技、出海等）中寻找投资标的
- 对科技股进行估值判断，避免高估值陷阱和低估值陷阱
- 情绪高涨期需要锚定安全边际，判断"预期如何变为现实"
- 自上而下构建投资战略，从宏观方向筛选到具体标的

## 方法步骤

### 一、三维选股框架（自上而下）

从投资战略出发，用三个维度筛选标的：

| 维度 | 含义 | 判断标准 |
|:---|:---|:---|
| 出海 | 是否具备全球化竞争力和海外收入增长 | 海外营收占比及增速 |
| 科技（新质生产力） | 是否属于政策鼓励扶持的科技方向 | 政策定位、产业趋势 |
| 估值 | 当前价格是否提供安全边际 | 估值合理性（见下文） |

**决策规则**：
- 满足一个维度 → 可以研究观察
- 满足两个维度 → 可以重点研究
- 三个维度全满足 → 核心标的

### 二、科技股估值方法（双视角平衡）

**核心原则**：短期看叙事，长期看业绩。大部分个股拉长时间看都要回归到业绩这一条线上来。

**视角一：看当前（避免高估值陷阱）**
- 用过去和当前的现金流判断现在股价是否合理
- 价值投资重现实：过去和现在才是确定的，未来是不确定的
- 目的：避免估值过高，导致未来即使高增长也不能弥补当前估值的不合理

**视角二：看未来（避免低估值陷阱）**
- 科技股高溢价本质是对未来现金流的折现预测
- 预测意味着不确定性：人们时而乐观、时而怀疑，发展路径充满变数
- 目的：避免即使估值很低，但发展不及预期，陷入低估值陷阱

**平衡结论**：
- 估值合理 + 增长稳定 → 值得重点研究和关注
- 新质生产力是政策方向，但投资层面要做好估值和未来预期之间的平衡

### 三、情绪高涨期的估值锚定

- 情绪高涨后，人们更加重视"预期怎么变为现实"
- 大部分人心中有恐高心理，估值就相当于心中的安全锚
- 股价实质上就是围绕合理估值波动的——估值本身就是安全锚

## 关键指标

| 指标 | 用途 | 备注 |
|:---|:---|:---|
| 当前现金流/业绩 | 判断估值是否脱离现实 | 确定性高，是安全锚的基础 |
| 未来业绩增速预期 | 判断成长性能否支撑当前溢价 | 不确定性大，需保守估计 |
| 估值分位数 | 判断当前价格在历史区间的位置 | 情绪高涨期尤其重要 |
| 海外营收占比/增速 | 出海维度筛选 | 全球化竞争力验证 |
| 政策扶持力度 | 新质生产力维度筛选 | 方向性判断 |
| 业绩兑现节奏 | 叙事→业绩的转化进度 | 短期看叙事，长期看业绩 |

## 案例

**2026年7月科技股回调期的应用**：

- **背景**：科技股经历大幅上涨后回调，市场情绪从亢奋转向恐高
- **三维筛选应用**：在出海+科技+估值三维中，回调后部分标的估值回归合理区间，满足两个以上维度的标的进入重点研究池
- **估值平衡应用**：
  - 看当前：回调后估值是否已回到现金流可支撑的范围
  - 看未来：AI/新质生产力方向增长确定性如何，能否支撑中期业绩兑现
- **结论**：拉长周期看，估值合理、增长稳定的新质生产力相关标的值得重点研究关注

> "投资科技股，不仅要看未来，也要看当前。"
