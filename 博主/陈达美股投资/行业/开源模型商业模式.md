# 开源模型商业模式

**核心判断：没有云计算，开源模型很难赚到钱；开源模型的商业模式大致有六条路，其中第六种"不靠模型赚钱"（母体输血/战略亏损）最牛逼——这是 DeepSeek（锋哥）的方式。**

## 行业概况

市场对"开源模型如何商业化"的讨论常陷入"模型免费=不赚钱"的误区。陈达美股投资指出：很多人还是不明白没有云计算，开源模型很难赚到钱。开源模型的商业模式主要有六条路，除了最后一条，其余都很难赚到钱：

1. **卖 API 托管服务**（最直接）——模型开源，但用户不想自己买卡部署，用官方 API 按 token 计费，如 DeepSeek。
2. **双许可 / 开源核心，闭源增值**——核心模型开源，增值能力闭源收费。
3. **云平台分发**（用别人的云收钱）——自己不建云，把模型放进 AWS Bedrock、Azure AI、阿里云百炼等平台售卖，与云厂商分成，如 Llama。
4. **企业服务与定制**——面向企业客户做私有化部署与定制，如百川。
5. **C 端订阅**（模型免费，产品收费）——模型本身免费，靠产品订阅变现，如 Kimi。
6. **不靠模型赚钱**（母体输血 / 战略亏损）——模型不承担盈利任务，由母公司或战略投入供养，如 DeepSeek。

其中第六种模式最牛逼，这是"锋哥"（DeepSeek）的方式。

## 关键数据

| 路径 | 代表 | 盈利模式 | 评价 |
|:---|:---|:---|:---|
| 卖 API 托管 | DeepSeek 官方 API | 按 token 计费 | 最直接 |
| 双许可 | 开源核心+闭源增值 | 开源引流、增值收费 | 需有差异化增值 |
| 云平台分发 | Llama | 与云厂商分成 | 用别人的云收钱 |
| 企业服务与定制 | 百川 | 私有化部署收费 | 服务重、难规模化 |
| C 端订阅 | Kimi | 产品订阅 | 模型免费、产品收费 |
| 母体输血/战略亏损 | DeepSeek | 不靠模型赚钱 | 最牛逼、最可持续的打法 |
