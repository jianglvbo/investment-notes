# 存储行业

## 行业概况

2026年中，存储板块成为全市场焦点，但6月财报发布前市场情绪偏弱。核心矛盾在于：卖方上调存储市场空间（TAM）预测的幅度，大幅超过云厂商实际资本开支指引——两者出现严重背离。JPM在香港与超50家机构投资者交流后，判断云厂商后续会上调数据中心硬件资本开支指引，但上调幅度存在极大不确定性，当前该变量是影响存储板块情绪70%的核心因素。[^data-1]

值得注意的是，股价不涨了以后大家找原因，其实都是老生常谈——高盛在三月份同样找投资者谈一谈，当时的观点与担忧几乎一模一样。这说明市场的焦虑是结构性的，而非某一季度的偶发事件。

**AI记忆=存储的投资视角（2026-08-14 补充）**：关于"memory"的讨论有点形而上学的气味，但现实点而言，你没办法靠投资"类人记忆"而赚钱，只能靠投资"硬件+软件做出来的技术、商品、服务"而赚钱——那么瓶颈到底在哪，脖子卡在了哪里。大模型就没有记忆，那谈什么记忆是 rate limiter 呢？没有的东西，是什么瓶颈？所谓模型有记忆，一定是在硬件上来谈。AI投资，记忆就是存储，存储就是记忆。memory 之于 agentic AI 是一语双关，既可以指硬件也可以指软件，但 bottleneck 就是硬件——agent 的 memory failure 本质上是硬件不够，软件策略和技术的实现根本不是什么瓶颈。

## 关键数据

**供需格局**：DRAM比NAND更缺（自给率50-60% vs NAND 70-80%），短缺延续到2028E。NAND消费级需求下修超预期，但KV cache offloading的企业SSD需求异常强，厂商预测500EB、2027E同比接近+50%。[^data-2]

**LTA（长期合约）进展**：LTA讨论明显升温，美光在最新业绩里把结构（时长、定价、目标利润率）讲得很细。JPM判断最终过半合约量会走LTA，关键是把floor price和margin守在AI之前的水平之上——这是盈利持久性的核心。LTA没锁死全部量，2027年可能更高价再签；量的可见性、"take or pay"条款比价格上限更值钱。短期margin封顶是担心点，但拉长看over-the-cycle盈利——这正是对"存储是周期股、下行期该跌50-70%"那套说法最强的反驳[^conflict-1]。

**HBM定价分歧**：多数买方赌明年HBM涨2倍（y-y），想靠HBM ASP上修带EPS。JPM测算HBM现在约$1.8/Gb，还低于非HBM server存储的~$2/Gb，纯经济账投资者站得住。但厂商是按DRAM/NAND/HBM整体盈利跟客户谈的，且HBM每年谈一次价（不像传统存储签3-5年），下一年还能涨。综合下来JPM给25-30% y-y更靠谱。[^data-3]

**HBM技术路线**：韩厂2Q26送样后，市场认可HBM4E主流是12Hi而非16Hi（JPM模型设12Hi:16Hi = 65%:35%），NVDA端下行有限。反倒是Google TPU、AWS Trainium需求更大，HBM短缺会延续整个预测期。

**库存风险**：下行周期通常从库存激增开始，但当前短缺下主要客户库存在下降，几乎没有意外去库存风险。有投资者提示电力可能成瓶颈、拉大上游半导体和下游机架装机的gap。

**2027E定价假设**：每季单位数%涨幅，一半量走LTA、一半走合约价。基数差（韩厂3月季度涨得本就更多）和产品结构差（LPDDR拉低blended ASP，server比mobile grade贵30-40%/GB）是近期定价的关键变量。

**闪迪高毛利预期（2026-08-13 补充）**：闪迪（SNDK）预计 2028 至 2030 财年非 GAAP 毛利率约为 80%、非 GAAP 营业利润率约为 75%。博主评价"这生意做得如此自信"，并自述"财报暴跌那晚没白抄你"——财报利空后抄底闪迪。
