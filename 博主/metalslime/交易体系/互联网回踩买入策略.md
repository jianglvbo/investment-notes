# 互联网回踩买入策略

## 规则

1. 互联网**不要追高买**，想配置的等回踩
2. 当前位置的压力有一点要被消费股影响
3. 互联网会调，因为消费属性太强，但**内含价值高于消费**
4. **创新药、红利、互联网回踩是买点**，不会有前低那种位置了
5. 消费是有可能把涨幅回踩一大部分然后不一定是买点，可能横盘很久

## 适用条件

- 互联网板块从底部反弹后出现回踩
- 消费股波动影响到互联网走势
- 创新药、红利板块同步调整
