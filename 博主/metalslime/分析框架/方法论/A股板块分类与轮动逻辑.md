# A股板块分类与轮动逻辑

## 核心框架

将A股主要板块按**与AI硬件的关系**进行分类定位：

| 板块 | 定位 | 特征 |
|:---|:---|:---|
| 消费 + 微盘 + A股软件 | **硬件的反面交易筹码** | 三者是同类资产，作为硬件的再均衡对手盘 |
| 互联网 | **消费+AI infra结合体** | 涨了是AI infra逻辑，跌了回归消费逻辑 |
| 红利 | **孟菲斯信仰者长周期贝塔** | 配置型标的，适合长周期持有 |
| 出海（含创新药） | **成长股序列** | 需要落实到具体选股与择时 |
| 泛周期股 | **偏红利类资产** | 需要落实到具体选股 |

## 分析过程

### 硬件 vs 反面的跷跷板

- 消费、微盘、A股软件本质上都是AI硬件的**反面交易筹码**
- 当硬件板块回调时，资金向这些板块再均衡
- **短期微盘股占优**

### 互联网的双重属性

- 上涨时被归入AI infra（算力基础设施）
- 下跌时被归入消费（面临消费同样的基本面困境）
- 投资者需要判断当前主导的是哪个叙事

### 红利的配置价值

- 红利股是"孟菲斯信仰者"（相信长期价值回归的投资者）的贝塔配置标的
- 不适合短线博弈，适合长周期持有

## 关键判断

- **短期微盘股占优**：在硬件回调的再均衡中，微盘弹性最大
- 互联网板块需要根据市场叙事切换来判断
- 出海和创新药需要个股层面的精选和择时，不能简单板块配置
