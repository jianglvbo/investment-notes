# AI4S价值捕获框架：从工资池到探索税

## 适用场景

用于判断 AI 应用阶段的价值捕获载体与交易方向。核心问题：AI 的价值从"自动化知识工作（工资池）"向"加速科学研究（探索税）"延伸时，资本市场应该交易什么。

## 方法步骤

**第一步：识别 AI 商品化产物的四个阶段**：

1. Chatbot → Coding Agent → General Enterprise Agent → Scientific Agent；
2. 前三者主要是在重新分配现有软件和人工预算（捕获工资池），第四个（AI4S/Scientific Agent）有机会直接进入研发资本支出和新产品创造（收取探索税）——这对估值非常关键。

**第二步：判断各阶段硬件与应用的表达**：

- **Coding 与 Agent 阶段**：硬件是商业化最好的表达（硬件市值占比高）；
- **AI4S 阶段**：AI 偏赋能，下游行业与 AI 平台转化是商业化表达——硬件不是最好的交易载体，AI 被迫赋能其他行业导致其他行业市值提升（AI 吞噬不了的东西有很多）；
- **Physical AI 阶段**：硬件内部切换，从云上运算演变成终端硬件。

**第三步：用价值捕获形态筛选标的**。超工资池价值 = 交易流抽成 + 资产收益分成 + 风险溢价 + IP 所有权 + 新需求创造 + 网络垄断租金。

## 关键指标

- AI4S 的核心约束：**ai4s 只会围绕医药**——只有医药领域存在大量知识产权交易，其他行业的研发奖励回馈机制大多无法通过知识产权交易实现，研发价值与最终产值之间的漏斗差距巨大，大模型难赚大钱。不考虑医药，ai4s 几乎没有大的商业价值。
- 证据链进度：AI 药物发现目前可能正在改善"造出一个像药的分子"的能力，但还没有充分证明能显著改善"选对人体疾病机制"的能力。
- 交易节奏：应用两条线（探索税的 ai4s + 软件的 FDE）都没结束；如果结束，会在硬件反弹结束之后结束，而不是提前。

## 案例

- **估值叙事**：AI for Science 解决了一个关键估值问题——"年收入几十/几百亿美元的软件公司凭什么值接近一万亿美元"。若答案变成"AI 能提高发现新药/新材料/新能源技术的速度"，TAM 与长期价值捕获空间完全不同，trillion-dollar valuation narrative 由此成立。
- **具体信号**：Anthropic 招聘生科研究员做实验 → 金斯瑞与 Twist 启动；市场在 AI for Science 叙事发酵初期存在交易机会[^date-1]。
- **反向警示**：当 ai4s 或 AI 交易抽成模式（大模型购物收广告费、成立保险公司、取代银行证券）确立头部大模型出现业务增量时，硬件才重新值得交易——但似乎只有 ai4s 和少部分零和博弈的金融需求更适合闭源大模型。

[^date-1]: 截至2026年8月 — AI4S 叙事处于早期发酵阶段，需关注 AI 药物发现证据链（改善分子生成 vs 改善靶点选择）与知识产权交易落地进展
