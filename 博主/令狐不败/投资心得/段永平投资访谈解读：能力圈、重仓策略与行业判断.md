# 段永平投资访谈解读：能力圈、重仓策略与行业判断

## 背景

段永平最新的访谈值得反复阅读，每看一遍都有新收获。他的投资哲学正如他的网名一样，真正做到了"大道至简"。其中"买股票就是买公司"这句话虽已被说烂，但本次访谈中仍有一些非常值得玩味的观点[^enhance-1]。

## 经验教训

## "不懂"哲学：说得最多的三个字

段永平在整场访谈中说得最多的一句话就是"我不懂"、"我不知道"。他坦言自己不懂通用电气、不懂石油、不懂AI、不懂机器人、不懂台积电、不懂英伟达、不懂谷歌和特斯拉——尽管他都从这些公司赚到过钱，但他还是说自己不懂，即便懂，也只是懂一点。就连让他赚了几十倍的网易和拼多多，他也不是完全懂。这是一种很反直觉的现象：懂得越多的人，反而越觉得自己什么都不懂；而有些明明懂得不多的人，却觉得自己什么都懂。市面上很多"大师"，随便扔给他一个股票代码，几分钟就能给出一二三的投资建议，仿佛没有他们不懂的公司。**段永平说自己真正懂的公司就三家：腾讯、苹果、茅台[^enhance-3]。**

- 懂腾讯：因为他本身就是做游戏出身
- 懂苹果：因为他本身是手机大厂出身
- 懂茅台：因为茅台这家公司的生意足够简单

所谓的安全边际，就是你对这家公司有多懂。

### 重仓策略：苹果仓位最高超九成

段永平说自己持有苹果最重的时候仓位在九成以上。要舍得在好公司上面重仓，而不是像"开超市"一样，几十只股票各买一点。这种分散策略的问题在于：即便你运气好，某只股票涨了十倍，但对整体收益影响也有限，不如直接买ETF，还能省手续费。段永平在采访中提到了一个百分之百赚钱的方法：买标普500。那么重仓什么样的公司？答案是好公司，而且要"显而易见"地好。他带黄峥去参加巴菲特午餐时，巴菲特举过一个**姚明比喻**：如果姚明走进餐厅，你一定觉得他很高；如果你没办法判断这个人高不高，那就说明这个人还不够高。好和坏都是显而易见的。段永平美股持仓最高的是苹果，A股是茅台，港股是腾讯——这些都是大家长久以来公认的好公司。但也正因为好得太明显了，很多人反而不想买，非要去看那些垃圾公司，而且一定要三天两头出问题的。格雷厄姆将这种行为称作**"蝗虫"**——在庄稼地里跳来跳去，总觉得投资和撒网一样，要广撒网、什么鱼都沾一点。但凡有只股票多看了一眼，立马就开始厌烦。这类人其实不是在选股，而是在被各种股票不断地分散注意力。

### 不炒股要投资：量化宣告投机分子的死亡

段永平说炒股80%的人都在亏钱，也不要觉得自己特殊能成为那20%。特别是在当下A股行情波动剧烈的情况下，散户很难战胜市场。所以一定要有投资者的心态，看到好的公司、懂的公司，拿着就行，做好长期主义的打算。虽然网上一直在骂量化交易，但量化对这个市场是有益的。它的出现会**逐渐宣告投机分子的死亡**——你还想通过看图看线、听消息、做趋势，难度会越来越大。量化其实是在帮助市场完成出清，从价值投资的角度看，至少不会有坏处。

### 行业判断：几个鲜明的观点

- **电动车不是一个好生意**：最后大家都会活得很艰难
- **自动驾驶公司**：最后也只会剩下一家。说白了，汽车这个行业最终会像手机一样，出现一家"苹果"，拿走行业80%的利润
- **人形机器人**：段永平觉得现在的人形机器人很奇怪——为什么非得有个头呢？如果说有头还能说得过去，那为什么非得要有胸？它的价值到底体现在哪里？这一点他也百思不得其解

## 借鉴意义

段永平的访谈看似在反复说"我不懂"，实则讲的是一种极其稀缺的投资品质——承认自己不懂、只重仓真正看懂的好公司、长期持有、不投机。[^enhance-2]这套方法论的反面，就是市场上那些看似什么都懂、实则什么都赚不到的"大师"们。对普通投资者的启示：

1. **收窄能力圈**：与其广撒网，不如深耕少数几家真正懂的公司
2. **敢于重仓**：在真正看懂的好公司上，仓位要够重
3. **接受"不懂"**：不懂就不碰，不要因为别人赚钱了就跟着买
4. **长期主义**：炒股80%亏钱，投资才能穿越周期
