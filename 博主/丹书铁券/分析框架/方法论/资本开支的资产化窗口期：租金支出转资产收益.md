# 资本开支的资产化窗口期：租金支出转资产收益

## 适用场景

评估云服务/算力类科技公司的资本开支决策时使用。当市场因公司"烧钱"、短期亏损而质疑其财务健康度时，本框架用于判断：这笔资本开支是在买未来资产，还是在烧钱买增长？核心是识别"把租金支出变成资产收益"的关键窗口期。

## 方法步骤

### 一、区分三块业务，分别看

以公司披露结构拆解：**主业**（老本行，看现金流扎实度）、**期权/新业务**（看是否为未来印钞机）、**算力/云业务**（看真实增长与供需缺口）。

### 二、用剔除自用的增速看云业务真实景气度

云业务（剔除自用）仍增20%以上，说明对外需求的真实增长没有被内部消耗稀释——这是判断算力需求是否真实的关键口径。

### 三、用"高价租对手算力"识别供给缺口

还得高价租对手的算力，说明自身算力供给不足、市场需求旺盛——**租对手的每一分钱都是给别人打工的利润**。这节骨眼不加码资本开支，难道等以后给竞对打工？

### 四、资产化视角：市场只盯着烧钱，没看见窗口期

市场只盯着烧钱亏损，没看见这是把"租金支出"变成"资产收益"的关键窗口期——现在每多建一份自用算力，未来就少一份租对手的钱；新业务短期亏损是门票，投的是未来印钞机。

### 五、用主业现金流兜底

主业两位数增长、现金流扎实，是资本开支的底气来源——没有主业现金流支撑的烧钱是危险的，有主业兜底的烧钱是资产化。

## 关键指标

| 指标 | 判断标准 |
|:---|:---|
| 主业增速与现金流 | 两位数增长、现金流扎实 = 资本开支有底气 |
| 新业务亏损性质 | 短期亏损是"门票"还是无底洞（是否投未来印钞机） |
| 云业务剔除自用增速 | ≥20% = 真实需求未被自用稀释 |
| 是否高价租对手算力 | 是 = 供给缺口明确，资本开支窗口期已到 |
| 租金支出 vs 资产收益 | 资本开支能否把租金支出转成自持资产收益 |

## 案例

**某云/算力科技公司（丹书铁券持仓，未点名）**：主业两位数增长、老本行现金流扎实；新业务短期亏损被市场视作"烧钱"；但云业务（剔除自用）仍增20%以上，还需高价租对手的算力——丹书铁券判断这是把"租金支出"变成"资产收益"的关键窗口期，市场只盯着烧钱而忽略了资产化的长期价值。
