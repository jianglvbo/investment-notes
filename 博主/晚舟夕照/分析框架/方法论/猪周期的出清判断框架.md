# 猪周期的出清判断框架

## 适用场景

判断猪周期所处阶段与参与方式：通过观察落后产能是否出清，推断平均猪价中枢与头部企业超额收益的变化，从而决定"做波段"还是"离场"。适用于生猪养殖行业的周期位置判断，也可迁移到其他以"产能出清决定价格中枢"为特征的周期行业。

## 方法步骤

### 一、看现金流约束下的出清压力

生猪繁殖是需要现金流的。从几家小猪企的仔猪出栏来看，出栏规模-负债率的滞后效应大概率会重现——上次是正邦、傲农，这次会有好几家。小养殖企业现金流断裂会先于行业见底，**出栏规模扩张与负债率攀升的错位是风险的前置信号**。

### 二、评估这次出清的弹性

这次弹性会比想象中要大一点——因为有能力逆周期扩繁对冲的厂家被按住手不让扩了。当逆周期对冲力量被政策压制时，出清一旦启动，价格反弹的弹性更大。

### 三、用平均猪价判断周期位置

落后厂家不被淘汰，成本领先的公司依然有超额收益；什么时候落后厂家被出清了，头部厂家的超额收益会出现显著的下降。如果用平均猪价来看很简单：**落后厂家不出清，周期拉长的平均猪价依旧较高；出清了，平均猪价会进一步走低，因为行业平均成本降下来了。**

### 四、对应参与策略

猪周期就是这么个简单的故事。落后厂家不出清，就是永远的波段；出清了就要小心了，处于安全的角度就别玩了。**出清前是可以反复参与的波段市，出清完成后反而要警惕头部超额收益消失。**

## 关键指标

| 指标 | 用途 |
|:---|:---|
| 小猪企出栏规模-负债率错位 | 出清压力的前置信号（正邦、傲农模式是否重现） |
| 逆周期扩繁能力 | 能否对冲出清弹性（被政策按住时弹性更大） |
| 落后产能出清状态 | 决定平均猪价中枢与头部超额收益 |
| 平均猪价 vs 行业平均成本 | 判断周期位置：平均成本降下来意味着出清接近完成 |
| 头部厂家超额收益 | 出清完成后显著下降，波段逻辑终结 |

## 案例

**正邦、傲农**：上一次猪周期出清的代表案例——出栏规模扩张与负债率攀升的滞后效应最终导致现金流断裂，行业出清后格局重塑。

**生猪养殖行业（2026-08）**：晚舟夕照判断几家小猪企将重现出清，且因逆周期扩繁对冲被政策按住，这轮出清弹性可能大于想象。[^date-1]

[^date-1]: 截至2026年8月 — 需跟踪小猪企出栏/负债数据与扩产政策约束变化，若逆周期扩繁约束放松，则"出清弹性更大"的判断需修正
