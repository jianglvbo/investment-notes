# 公募重仓股变迁作为行业底部信号

## 核心逻辑

当一个行业的代表性个股从公募基金十大重仓股中完全退出时，恰恰说明该行业已被机构彻底抛弃，筹码出清接近完成，反而构成底部信号。"当茅台也退出、完全没有白酒之际，我更觉得这再次表明现在就是白酒底部。"

## 数据验证

### 2026年二季末十大重仓股（全科技）

中际旭创、新易盛、寒武纪、宁德时代、中微公司、北方华创、兆易创新、海光信息、东山精密、源杰科技

### 2026年一季末十大重仓股（科技+消费混合）

中际旭创、宁德时代、新易盛、腾讯控股、**贵州茅台**、东山精密、紫金矿业、阿里巴巴-W、药明康德、立讯精密

### 历史脉络（2018年起）

- 2018年起：白酒多支个股进入重仓股（茅台、五粮液、泸州老窖、山西汾酒、古井贡酒）
- 2018-2025年：茅台始终在列
- 2025年：白酒陆续退出，只剩贵州茅台一支
- 2026Q1：茅台仍在
- 2026Q2：茅台终于退出，白酒完全清零

## 逆向推理

1. **机构抱团到极致 → 瓦解 → 完全退出**：这是一个完整的筹码出清周期
2. **完全退出 = 无人问津 = 卖压枯竭**：当所有机构都已清仓，边际卖压消失
3. **常识检验**：当前十大重仓全是科技股，"不少都明显不符合常识"——这本身也是科技过热的信号
4. **双向信号**：白酒完全退出是白酒底部信号，同时也是科技过度拥挤的警示

## 适用条件与局限

- 适用于有长期消费基础的行业（白酒不会消失），不适用于真正被替代的行业
- 需要区分"周期性被抛弃"和"结构性衰退"
- 底部信号≠立即反转，可能还需要较长时间磨底
- 单一指标需结合估值、基本面等其他维度交叉验证
