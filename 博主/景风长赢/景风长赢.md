# 景风长赢

## 擅长与局限

**擅长**：多行业产业投资（医药、新能源、科技、高端材料、化工、互联网）、周期定位与左侧建仓、组合均衡配置与再平衡、宏观经济与资产配置逻辑、大宗商品周期判断

**盲区 / 局限**：对创新药管线类标的明确不纳入能力圈（无法跟踪稼动率和技术演进）；持仓30-40只，单只深度可能有限；观点表达偏宏观叙事，具体估值数据较少
