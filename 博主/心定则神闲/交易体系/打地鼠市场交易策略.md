# 打地鼠市场交易策略

## 规则

1. 极致的筹码博弈让市场完全变成一场**打地鼠游戏**
2. 对付打地鼠市场的最好方法：**涨就卖，跌就买**
3. **大涨就大卖，大跌就大买**——玩的是跟大盘做个对手盘
4. 筹码游戏主导的市场，不高低切就是对自己的资金不负责任

## 适用条件

- 市场处于存量博弈阶段，缺乏增量资金
- 板块轮动极快，无持续性主线
- 成交量萎缩，量化资金间歇性进出
