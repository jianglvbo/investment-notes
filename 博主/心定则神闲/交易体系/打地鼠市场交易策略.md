# 打地鼠市场交易策略

## 规则

1. 极致的筹码博弈让市场完全变成一场**打地鼠游戏**
2. 对付打地鼠市场的最好方法：**涨就卖，跌就买**
3. **大涨就大卖，大跌就大买**——玩的是跟大盘做个对手盘
4. 筹码游戏主导的市场，不高低切就是对自己的资金不负责任

### 箱体震荡的具体落地（2026-08-17 补充）

这个位置，**无所谓什么估值合不合理，几乎所有股票都没有太大的长期投资空间，只有来回博弈的吃情绪差价操作机会**。跌多了就看涨，涨多了就看跌。**只要股价还在箱体里面震荡，那唯一的交易原则就是买便宜的，买股价跌到了箱底的；卖贵的，卖股价涨到了箱顶的。** 如果一定按耐不住要动手，那主打的就是一个**短期赔率**——在箱体两端的赔率才划算。

## 适用条件

- 市场处于存量博弈阶段，缺乏增量资金
- 板块轮动极快，无持续性主线
- 成交量萎缩，量化资金间歇性进出
- 个股/板块处于箱体震荡形态（无趋势），此时估值失效、只按情绪差价操作
