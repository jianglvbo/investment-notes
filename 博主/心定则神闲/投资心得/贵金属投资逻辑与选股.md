# 贵金属投资逻辑与选股

## 背景

2026年8月5日，贵金属板块出现修复行情，金价有望从平台区突破，市场流动性回升。博主在此背景下加仓贵金属，并系统阐述了选股逻辑。

## 经验教训

### 核心逻辑

1. **贵金属的避险属性**：在地缘风险加剧时，黄金白银兼具业绩支撑和预期空间，还能规避地缘风险，优于科技股的"火中取栗"
2. **加仓信号**：金价有望从平台区走出来 + 市场流动性明显回升
3. **银价与股价联动**：银价站上所有均线上方，股价就能站上所有均线上方

### 选股排序

| 优先级 | 标的 | 理由 |
|:---|:---|:---|
| 第一梯队 | 兴业银锡(000426) | **两市最稀缺的白银标的，没有之一**；今年高点74.8，当前安全区间 |
| 第一梯队 | 中金黄金(600489) | 中长线最佳标的之一 |
| 第二梯队 | 山东黄金(600547) | 修复逻辑，资金不敢追高时的选择 |
| 短线修复 | 赤峰黄金 | 前期跌幅最大，短期有修复空间，但"有庄"，涨幅大后需注意 |

### 不买铜的三个理由

1. 工业金属走势不纯粹跟铜价挂钩
2. 大部分铜矿都在海外，受制于地缘关系
3. 铜股的技术指标明显没金银和小金属恢复得好
4. 基本面好的大盘铜股弹性差

## 借鉴意义

贵金属投资的核心在于选择**稀缺性最强**的标的，而非泛泛配置。兴业银锡作为白银标的的稀缺性使其成为首选。铜虽然基本面不差，但弹性、地缘风险和技术面均不如贵金属。

### 压制黄金走势的两个不利因子（2026-08-18 补充）

支撑黄金长期走强的因子很多，但**不要忽视压制黄金走势的两个重要不利因子**：

1. **走高的美债收益率**——无风险利率抬升，黄金不生息，机会成本上升（呼应 [[博主/心定则神闲/宏观/美债收益率上行与美股风险]]）；
2. **走强的美元指数**——美元计价资产走强，压制以美元计价的黄金。

**操作纪律：这两个因子只要有一个冒头，作为贵金属投资者就要保持警惕了。** 这是对多头逻辑的重要风控补充——贵金属并非单边看多，需要同时监控反向因子。
