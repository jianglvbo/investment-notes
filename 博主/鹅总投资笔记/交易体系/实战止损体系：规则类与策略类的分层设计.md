# 实战止损体系：规则类与策略类的分层设计

**核心判断：止盈止损的唯一目的是控制收益率的回撤——把赚到的钱最大程度留下来。只要围绕这一目的、实现了目标的止盈止损，就是对的操作，没有第二个评价标准。**

## 体系定位

止损属于操作系统的一部分（操作系统 = 行业配置 / 仓位规划 / 买入计划 / 风险控制），单独拿出来不完整。止损是操作系统中**最简单、最容易学习**的部分。

## 规则类止损（通用）

1. **百分比止盈**：浮盈达 20-25% 止盈
2. **区间涨幅止盈**：一波流涨幅达目标（如看好涨 70%，50% 介入，赚 20% 就走）
3. **打板止盈**：无成交 4 板止盈；40% 位置或烂板位置主动止盈
4. **盈利回撤止损**：爆赚 100% 后回撤 15% 开始考虑止盈，25-30% 回撤全部撤离
5. **分仓个股比例止损**：单票仓位满（不超 25%）后，单票亏 8% 硬止损 → 对总仓位影响不超 2%
6. **总仓位止损**：总仓位单次被干 -5% 且无其他规则约束 → 全仓硬止损

## 策略类止损（结合场景）

1. **正负零止损**：只要原来是赚的，浮盈被吃掉接近零之前无条件砍——"没有什么比眼看着从赚钱到亏钱而毫无反抗更愚蠢"
2. **基本面止损**：适合长期持股，基本面恶化或经营环境突变时止损（如游戏行业 A4 事件）
3. **形态止损**：适合大票流动性出问题，结合 K 线和止损比例（作者 0224 中免跌停介入 → 0303 加速破位 → 形态偏空 + 超仓位止损位 → 盘头止损，避免十多个点损失后低位买回）
4. **交易计划止损**：用得最多的方案，即"买入定胜负"——买入前定好为什么买、什么行业标的、仓位多少、止损怎么定；**买入理由变了，计划不一样，这部分仓位先清出去**

## 特别风控

- **网格买入与分仓**：仓位上限让单股风险影响最小化（不超 20%）
- **浮盈比例调整**：看好但介入时机差、易打止损线时，卖一半让浮盈从 10% 变 20%，不与止损体系冲突

## 使用原则

1. **买卖目标匹配**：短线买入就该短线止损；中途改长期持有 + 网格摊平 = 高位加仓一把亏光。"买入定胜负"——买入时点、仓位后期基本无法调整，升势很猛的票后期只有减仓和止盈两个选项
2. **买卖点不相容**：跌破 100 卖、98 又打到买点——买卖点无空间，除非做人肉量化，否则是送钱。买卖点要从价位和原因上明确区分

## 纪律

- **冷静期与复盘**：单票打到绝对止损位当天上风控、不开新仓；策略错的情况下砍仓再买大概率再错一次
- **以账户为绝对中心**：不管市场多精彩、票多好，心里只有账户回撤曲线——"我没有拿自己的钱去置气"
- **达到目标，容忍误差**：止损后马上涨太常见；卖飞不扣分、卖完暴跌加分，多次重复博弈下有效控制回撤就是成功——**不追求完美止损，追求相对完善的系统**
