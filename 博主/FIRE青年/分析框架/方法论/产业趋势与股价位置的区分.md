# 产业趋势与股价位置的区分

## 适用场景

当市场将某个产业方向（如AI）包装成"不可质疑"的王冠时，用于区分"产业长期向好"与"个股当前股价能否继续上涨"之间的关系。

## 方法步骤

核心原则：**方向正确，不等于价格永远正确**

1. **趋势判断与买入价格必须分开看**：二级市场是筹码从底部搬运到顶部再派发的游戏，不是"看好方向股价就持续走高"
2. **好公司可以有不好的价格**：看好AI 5-20年发展，不代表高位CPO不会连续多年不跌[^supplement-1]
3. **警惕宏大叙事套高位资产**：一旦某方向被包装成"不可质疑"，其他资产就被视为废铜烂铁 → 用这种方式理解市场一定吃大亏
4. **历史教训**：2000年初互联网浪潮——即使所有人都知道互联网会爆发，高位买入某些后来成为大厂股票的人也可能经历长期亏损甚至退出市场[^enhance-1]
5. **光伏新能源的前车之鉴**：2022年相信光伏宏大叙事的人，跌10-15%还能冷静，跌20-25%就开始"越跌越补"，最终栽大跟头

## 关键指标

| 维度   | 正确认知 | 常见误区          |
| :--- | :--- | :------------ |
| 产业趋势 | 长期向好 | 等同于股价永远涨      |
| 买入价格 | 必须审慎 | 好方向=好价格       |
| 宏大叙事 | 需警惕  | 不可质疑=应该All in |
| 越跌越补 | 需看位置 | 好东西跌了就该补      |

## 案例

- 2000年互联网泡沫：高位买入大厂也可能万劫不复
- 2022年光伏新能源：宏大叙事下越跌越补的惨痛教训
- 当前AI硬件股（CPO等）：看空高位CPO ≠ 看空AI产业
